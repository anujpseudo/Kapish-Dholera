# Aurelia Landmark — Smart City Real Estate Website

## Folder Structure
```text
aurelia-landmark-website/
├── index.html          # Semantic HTML5 markup for all sections & modals
├── style.css           # Responsive stylesheet with 3 luxury switchable color themes
├── script.js           # Interactive ROI estimator, filters, modals & mobile drawer
└── images/             # High-resolution architectural & township imagery + SVG logo
    ├── logo.svg
    ├── hero-skyline.jpg
    ├── about-landmark.jpg
    ├── project-greenfield.jpg
    ├── project-horizon.jpg
    ├── project-aerocity.jpg
    ├── walkthrough-preview.jpg
    ├── blog-infrastructure.jpg
    ├── blog-smartgrid.jpg
    └── blog-aviation.jpg
```

## Quick Start
Open `index.html` directly in any modern browser or serve locally with VS Code Live Server / `python -m http.server 8080`.
